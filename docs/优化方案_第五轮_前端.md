# ListingForge 第五轮优化方案（v1.4 → v1.5）· 前端专项

> 主题：**现代前端体验** —— 暗色模式、骨架屏、命令面板、成功彩带、无障碍
> 方法：前端专项审计（量化硬编码/交互/可访问性债务）+ GitHub 流行模式调研，10 项全部零依赖（vanilla）实现。

## 二、优化项与验收标准（全部零依赖 vanilla）

| 项 | 方案 | 验收 |
|---|---|---|
| P1 暗色模式 | 语义化色彩令牌改造（69 处硬编码 → CSS 变量）；`.dark` 主题（深灰非纯黑）；顶栏切换按钮；localStorage 持久化 + `prefers-color-scheme` 默认 | 亮/暗切换全组件协调；刷新保持；README 双主题截图 |
| P2 骨架屏 | 结构化/生成/校验三处异步等待渲染形状匹配的 shimmer 骨架（卡片/行/徽章形状） | 异步期间骨架可见、完成后无布局跳动 |
| P3 ⌘K 命令面板 | Ctrl/⌘+K 唤起；模糊搜索：六个步骤、历史商品切换、暗色切换、导出 CSV；上下键 + 回车执行 | 键盘全流程可达 |
| P4 成功彩带 | 上架全部成功触发 canvas 彩带（内联实现，粒子/重力/渐隐） | 冒烟断言 canvas 出现；视频可见 |
| P5 自定义模态 | promise 化 `uiConfirm()` 替换 2 处原生 confirm；暗色协调 | 两处流程行为不变 |
| P6 一键复制 | Listing 卡片标题/五点/描述 hover 复制按钮，clipboard + toast 反馈 | 剪贴板内容正确 |
| P7 图片灯箱 | 点击白底主图/变体/场景图放大预览（ESC/点击关闭） | 冒烟断言打开/关闭 |
| P8 键盘快捷键 | 1-6 切步骤、D 切主题、? 显示快捷键帮助；输入聚焦时忽略 | 冒烟断言数字键导航 |
| P9 进度与动效 | 顶栏细进度条（步骤完成度）；生成统计数字 CountUp 动效 | 视觉验证 |
| P10 A11y | aria-label 补齐（步骤导航/按钮/灯箱）；`:focus-visible` 样式；彩带动画 `prefers-reduced-motion` 降级 | 键盘可完整操作；reduced-motion 生效 |

## 三、范围控制

- 不引前端框架/构建链/任何 npm 依赖（零构建原则不动摇）；
- 命令面板为轻量自研（~80 行），不引入 cmdk 类库；
- 不做移动端深度适配（保持桌面演示优先，仅保证不崩）。
