# ListingForge 第二轮优化方案（v1.1 → v1.2）

> 方法：对 v1.1 做全面复查（缺陷挖掘 / 安全审计 / 生成质量 / 测试盲区 / 文档一致性），共发现 13 项待改进点，按 P0 缺陷安全 → P1 功能与质量 → P2 文档交付 三层组织，全部执行并验证。

---

## 零、复查发现（审计结论）

| # | 层面 | 问题 | 严重度 |
|---|---|---|---|
| 1 | 缺陷 | **重复生成物料翻倍**：第 3 步多次点击"一键生成"，DB 中 Listing 无限累积（实测两次生成 2+2=4 条） | 🔴 高 |
| 2 | 安全 | **上传文件名路径穿越**：`dest = dir / f"upload_{ts}_{image.filename}"` 直接拼接原始文件名，`../../evil.png` 可写出上传目录 | 🔴 高 |
| 3 | 安全/性能 | **大图直送 Qwen-VL**：8MB 上传图 base64 后 ~10.7MB 直接送模型（逼近接口上限、慢、费流量）；且手机照片 EXIF 旋转未处理 | 🟠 中 |
| 4 | 安全 | 前端 PIM 属性/卖点/关键词渲染未转义（数据源自模型输出，存在注入面） | 🟡 低 |
| 5 | 功能 | 审核工作台修改字段后没有"保存"按钮，只有放行/驳回才隐式保存，切走即丢 | 🟠 中 |
| 6 | 功能 | 后端已有 `DELETE /api/products/{id}`，前端无删除入口，垃圾商品无法清理 | 🟡 中 |
| 7 | 展示 | 阿语 Listing 以 LTR 排版渲染，标点与语序显示错乱 | 🟡 中 |
| 8 | 功能 | 生成结果页只显示前 3 条，"另外 N 条"看不到 | 🟡 低 |
| 9 | 规则 | 方案承诺的"关键词布局"无校验支撑：标题未检查核心关键词命中 | 🟠 中 |
| 10 | 规则 | 规则引擎的 `truncate`/`truncate_bullets` 仍是字符硬切，与 v1.1 生成端词边界修复不一致，会产生残句 | 🟡 中 |
| 11 | 测试 | 测试盲区：生成幂等、发布幂等（重复上架应 400）、路径穿越、关键词规则均无覆盖 | 🟠 中 |
| 12 | 工程 | `.gitignore` 缺 `.env`（密钥可能误提交） | 🟡 低 |
| 13 | 文档 | 技术说明 API 表缺 `validate_all`/`GET /api/products`/`DELETE`；规则总数文档落后（新增规则后需同步） | 🟡 低 |

## 一、优化项与验收标准

### P0 缺陷与安全

| 项 | 方案 | 验收 |
|---|---|---|
| R1 生成幂等化 | 生成前清除该商品未发布旧物料与未成功任务（published 保留），重复生成不翻倍 | 两次生成后 DB 仍为 N 条；回归测试覆盖 |
| R2 上传净化 | `Path(filename).name` 去路径 + 扩展名白名单（png/jpg/jpeg/webp） | `../evil.png` 落盘不逃逸；测试覆盖 |
| R3 VL 预处理 | 新增 `compress_for_vl`：>1.5MB 或长边>1600 的图压缩至长边 1024 / JPEG q85 再送模型；抠图前 `ImageOps.exif_transpose` 修正手机照片方向 | 大图上传走压缩路径；含 EXIF 图方向正确 |
| R4 渲染转义 | PIM 属性/卖点/关键词全部经 `esc()` 输出 | 代码审查 + 手工验证 |

### P1 功能补全与质量

| 项 | 方案 | 验收 |
|---|---|---|
| R5 保存草稿 | 审核台新增「💾 保存修改」按钮（复用 PUT 接口），不放行也能存稿 | 修改→保存→切走再切回，内容保留 |
| R6 商品删除 | 历史列表每项加删除按钮（confirm 确认），删除后自动切到剩余最新商品 | 删除后列表刷新、当前商品自动切换 |
| R7 RTL 展示 | 语言为 ar 的标题/五点/描述按 `dir="rtl"` 渲染 | 阿语条目标点与语序正常 |
| R8 展开全部 | 生成页"展开全部 N 条物料"toggle | 8 条全部可见 |
| R9 关键词规则 | 新规则类型 `keyword_hits`：标题需命中 PIM 核心关键词 ≥2（warn 级），四平台全配（规则总数 23→27）；生成端 Amazon 标题补关键词尾缀保证命中 | 亚马逊/速卖通/TikTok 标题均 pass；含单测 |
| R10 截断统一 | 规则引擎 `truncate`/`truncate_bullets` 改为词边界截断（复用统一 helper） | 不产生残句；单测覆盖 |

### P1 测试与工具

|---|---|---|

| R12 UI 冒烟脚本 | `scripts/ui_smoke.py`：Playwright 断言六步流（面板切换/矩阵/上架状态），输出 PASS/FAIL | 本机跑通 |

## 二、不做什么（范围控制）

- 不引入前端框架/状态管理库；不做移动端适配与暗色模式；
- 不接真实平台 API、不加多用户鉴权（保持 Demo 边界，见技术说明生产路线）；
- 不重写规则引擎结构（增量扩展类型即可，避免过度设计）。
