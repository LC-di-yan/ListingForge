# 体验方式（评审指引）

> 三种体验方式任选：①本地运行 ②看演示视频 ③读代码与 API

---

## 方式一：本地运行（推荐，2 分钟）

### 环境要求
- Python ≥ 3.10（开发环境为 3.12）
- 无需任何 API Key（默认模拟模式离线可跑）

### 步骤

```bash
# 1. 解压/克隆后进入目录
cd ListingForge

# 2. 安装依赖（约 30 秒）
pip install -r requirements.txt

# 3. 启动
python run.py

# 4. 浏览器访问
#    工作台  http://127.0.0.1:8000
#    API 文档 http://127.0.0.1:8000/docs
```

### 六步操作路径（约 3 分钟走完）

1. **商品录入**：点击 3 张示例商品卡中的任意一张（推荐「智能温显保温杯」），自动进入第 2 步；
2. **AI 结构化**：点「🧠 开始 AI 结构化 + 图片管线」→ 查看结构化 PIM 数据（材质/颜色/卖点/关键词）与图片管线产物（白底主图 + 4 种尺寸 + 场景图）→ 点「下一步」；
3. **文案生成**：平台默认全选 4 平台，语言点选「西语 ES」→ 点「✨ 一键生成全套 Listing」→ 查看 8 条物料的统计与预览 → 「下一步」；
4. **规则校验**：下拉框切换到「速卖通 · 英语」→ 看到「标题禁用促销词」等**不合规**标记 → 点「🔧 一键自动改写修复」→ 状态变全通过 → 「下一步」；（可切换「亚马逊 · 英语」对比：9 条规则全通过）
5. **审核放行**：点「✅ 放行」（或「批量放行全部 EN 主语言」）→ 「下一步」；
6. **一键上架**：点「🚀 将已放行 Listing 批量上架」→ 查看 4 个平台的上架状态回传与自动生成的运营任务清单。

### 切换百炼实时模式（可选，展示真实 AI 推理）

```bash
# 先在 https://bailian.console.aliyun.com 开通并创建 API Key
# Windows (PowerShell)
$env:DASHSCOPE_API_KEY="sk-xxx"; python run.py
# macOS / Linux
DASHSCOPE_API_KEY=sk-xxx python run.py
```

顶栏徽标从「🧪 本地模拟模式」变为「⚡ 百炼实时模式」后，结构化与文案均由 Qwen-VL-Max / Qwen-Plus 真实推理（调用失败自动降级模拟模式，页面不会报错中断）。

### 命令行 / API 体验（适合技术评审）

```bash
# 全流程 curl 版
BASE=http://127.0.0.1:8000
PID=$(curl -s -X POST $BASE/api/products/sample/bottle | python -c "import sys,json;print(json.load(sys.stdin)['id'])")
curl -s -X POST $BASE/api/products/$PID/structure | python -m json.tool        # F1 结构化
curl -s -X POST $BASE/api/products/$PID/generate \
  -d "platforms=amazon" -d "platforms=aliexpress" -d "languages=en" | python -m json.tool   # F2 生成
curl -s $BASE/api/products/$PID/listings | python -m json.tool                 # 查看与校验报告
```

完整自动化脚本（生成→校验→改写→放行→上架一键跑完）见仓库 `scripts/demo_e2e.py`。

## 常见问题

| 问题 | 处理 |
|---|---|
| 端口被占用 | `run.py` 中改 `port=8001` |
| 依赖安装慢 | `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 想重置数据 | 删除 `data/listingforge.db` 后重启 |
| 图片不显示 | 刷新页面；产物在 `data/uploads/` 下 |
| 上架按钮提示无已放行 Listing | 先在第 5 步放行至少一条（批量放行按钮最快） |
